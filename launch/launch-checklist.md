# Launch checklist

Last verified: 2026-08-14

## T-1

- Confirm README, release notes, CI, GHCR tags, and anonymous image pull.
- Recheck Meta docs and community rules.
- Prepare answers for security, pricing, Coexistence, and limitations.

## Launch

- Publish GitHub Release only after tag workflow and image verification pass.
- Submit at most one community post at a time.
- Stay available for technical questions.

## After

- Track issues.
- Fix docs if users misunderstand the inbound-only boundary.
- Do not repost unchanged copy.

## STOP

STOP - external promotion requires a separate explicit instruction.
